# Debate Atlas Prototype

토론 데이터를 인포그래픽 중심으로 재구성한 정적 프로토타입입니다.

## 포함된 기능

- 토론 상태별 KPI 요약
- 참여율, 인사이트 작성률, 설득률, 체류 시간 시각화
- 토론별 비교 카드
- 체크박스를 켰을 때만 참여자 닉네임 공개
- `data/debates.json` 기반 집계 데이터 로딩

## 실행

정적 파일이라도 `fetch()`를 쓰므로 로컬 서버로 실행하는 편이 좋습니다.

간단한 로컬 서버는 아래처럼 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열면 됩니다.

## 데이터 구조

실제 화면은 `data/debates.json`만 읽습니다. 원본 서비스에서 바로 읽지 않고,
하루 1회 정도 집계 결과만 이 파일로 내보내는 흐름을 권장합니다.

권장 이유:

- 과도한 요청을 피할 수 있음
- 개인 식별 정보를 저장하지 않도록 중간 단계에서 정리 가능
- 원본 서비스 운영자 입장에서 이상 트래픽처럼 보일 가능성이 낮음

## 권장 수집 방식

1. 수업 종료 이후 하루 1회만 집계
2. 토론별 숫자와 참여 체크만 저장
3. `studentId`는 저장하지 않음
4. 닉네임 공개는 필요한 화면에서만 토글
